# متجر الإلكترونيات - Store App (Flutter)

تطبيق متجر إلكتروني متكامل مبني باستخدام Flutter ومتصل بـ RESTful API.

## مميزات التطبيق
- عرض المنتجات وتصنيفاتها.
- البحث عن المنتجات وتصفيتها حسب التصنيف.
- إضافة العناصر إلى المفضلة مع حفظها محلياً.
- شاشة تفاصيل المنتج مع تأثير Hero Animation.
- شاشة إتمام الطلب مع التحقق من صحة رقم الهاتف (Validated Form).

## الشاشات الرئيسة
1. HomeScreen
2. CategoryProductsScreen
3. ProductDetailScreen
4. FavoritesScreen
5. CheckoutScreen

## طريقة التشغيل
1. قم بعمل `flutter pub get` لتنزيل الحزم.
2. شغل التطبيق باستخدام `flutter run`.
